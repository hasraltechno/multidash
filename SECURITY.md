# Security Policy

## Supported versions

Security fixes are applied to the latest release.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Instead, report them privately via
[GitHub Security Advisories](https://github.com/hasraltechno/multidash/security/advisories/new).

You'll get a response within a few days. Once the issue is confirmed and fixed, we'll credit you in the release notes unless you prefer to stay anonymous.
